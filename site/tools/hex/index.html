Magic numbers: files that introduce themselves

Most binary formats begin with a fixed byte sequence — a magic number — so software can identify the content without trusting the file extension. The Unix file command has worked this way since 1973. Rename cat.png to cat.zip and the bytes still say 89 50 4E 47: it's a PNG.

Fun collision: Java's CAFEBABE and Apple's fat-binary magic are the same four bytes — decoders disambiguate by whether the next field looks like a tiny architecture count or a class-file version. This inspector does exactly that. And not every format signs its first bytes: a .dmg is recognized by the 512-byte "koly" block at the end of the file, ZIP by its end-of-directory record — some files you identify by how they finish, not how they start.

Endianness: which end comes first

A multi-byte number like 0x12345678 can be stored big-endian (12 34 56 78, most significant byte first — network protocols, PNG, Java class files) or little-endian (78 56 34 12 — x86/ARM memory, ZIP, GIF, BMP, most Microsoft formats). The names come from Gulliver's Travels, chosen in a 1980 note by Danny Cohen — a joke about which end of a boiled egg to crack. When a number in a dump looks absurd (a 4 GB length in a 2 KB file), you're probably reading it with the wrong endianness.

Structure over soup

Binary formats are built from a handful of recurring shapes: fixed headers (SQLite's 100-byte header), length-prefixed chunks (PNG, RIFF/WAV, MP4 boxes), tagged segments (JPEG markers), tables of records (ZIP's central directory, ELF program headers), and trailing indexes (ZIP, PDF — which is why those formats survive appending). Once you can spot the shape, an unfamiliar format stops being noise.

Frequently asked questions

Is my file uploaded when I inspect it?

No. The file is read with your browser's File API and parsed by code running in your tab — it never leaves your machine. Only clicking Share uploads content (up to 256 KB), and those links expire after 30 days.

Which file formats does the hex inspector understand?

It structurally parses PNG, JPEG, GIF, BMP, ZIP, gzip, tar, ELF, PE/EXE, Mach-O, Java class files, WebAssembly, SQLite, MP4, RIFF/WAV, PDF, and the Apple family: binary plist, DMG, AppleSingle/AppleDouble, xar (.pkg/.xip) and icns. Beyond those, magic-byte detection identifies many more formats by signature, and every file gets the hex view, strings extraction and entropy analysis.

How can I identify an unknown file type?

Check its first bytes: most formats open with a fixed signature called a magic number. Drop the file into the inspector and it matches those bytes against known signatures — telling you what the file actually is, regardless of its extension.

What is the maximum file size?

64 MB per file. The whole file is held in your tab's memory while you inspect it, so the limit keeps the browser responsive.
