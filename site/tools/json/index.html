The whole grammar fits on a napkin

        

          JSON has exactly six value types: object, array, string,
          number, true/false, null. Douglas Crockford specified it in 2001 on
          roughly one page, and it hasn't changed since — that immutability is why everything speaks it.

Numbers are quietly dangerous

        

          The spec puts no limit on number size, but JavaScript parses numbers into 64-bit floats: integers above
          2⁵³−1 (9,007,199,254,740,991) silently lose precision. A tweet ID like
          1144332590000000001 becomes …000000000 after a round-trip through
          JSON.parse. APIs that hand out 64-bit IDs send them as strings for exactly this reason.
        


        
JSON ≠ JavaScript

        

          Close cousins, not twins: JSON requires double quotes and forbids comments, trailing commas and
          undefined. In the other direction, JSON permits U+2028/U+2029 unescaped, which for
          years made "valid JSON" that crashed as JavaScript. Treat JSON as a data format that merely dresses like JS.
        

      


      

        
Frequently asked questions

        
Why is my JSON invalid?

        

          The usual suspects are trailing commas, single quotes instead of double quotes, unquoted keys, comments, and
          NaN/Infinity/undefined values — all legal in JavaScript but not in
          JSON. Paste your document and the validator points at the exact line and column and explains the specific
          mistake.
        

        
Does JSON allow comments or trailing commas?

        

          No. Standard JSON (RFC 8259) forbids both. JSONC and JSON5 are separate, more permissive formats — which is
          why a config file that works in VS Code can fail in a strict parser.
        

        
Can I convert JSON to TypeScript types?

        

          Yes — the → TypeScript button generates interfaces from your document, merging the object shapes it
          finds across array elements and marking keys that don't appear everywhere as optional.
        

        
Is it safe to paste sensitive JSON here?

        

          The formatter, validator and TypeScript generator run entirely in your browser — your document is never
          uploaded. Nothing leaves your machine unless you explicitly click Share.
