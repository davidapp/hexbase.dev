Well-formed vs. valid

        

          XML draws a line JSON never needed: a document is well-formed when the syntax is right
          (every tag closed, one root, attributes quoted, & escaped) and valid when
          it also obeys a schema (DTD, XSD, RELAX NG). Browsers check well-formedness — and unlike HTML, XML parsers
          are draconian by spec: one bare ampersand and the whole document is rejected.
        


        
The five predefined entities

          Everything else (&copy;, &nbsp;…) is an HTML habit — in XML those are
          undefined unless a DTD declares them. Use numeric references like &#169; instead.

CDATA: the escape hatch

        

          <![CDATA[ raw <text> & symbols ]]> tells the parser "don't interpret any of
          this" — handy for embedded code or markup samples. The only thing it can't contain is the terminator
          ]]> itself.
        

      


      

        
Frequently asked questions

        
What is the difference between well-formed and valid XML?

        

          Well-formed means the syntax is right: every tag closed, one root element, attributes quoted, special
          characters escaped. Valid additionally means the document obeys a schema such as a DTD or XSD. This tool
          checks well-formedness, using the browser's own XML parser — so what passes here parses everywhere.
        

        
How do I test an XPath expression online?

        

          Paste your XML, type an expression like //book[@lang="en"]/title and run it. Matching nodes are
          listed — or the computed value, since XPath expressions can also return strings, numbers and booleans (try
          count(//book)). The tool uses the browser's native XPath 1.0 engine.
        

        
Why does my XML fail with an undefined entity error?

        

          HTML habits: entities like &nbsp; and &copy; are not part of XML. Only
          &amp;, &lt;, &gt;, &quot; and
          &apos; are predefined. Use numeric character references such as &#160;
          instead, or declare the entity in a DTD.
        

        
Is my XML uploaded anywhere?

        

          No — formatting, validation and XPath evaluation all run locally in your browser. Only the optional
          Share button uploads content, and those links expire after 30 days.
